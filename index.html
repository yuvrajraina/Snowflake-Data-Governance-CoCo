Frequently asked

Know the boundary before you begin.

Does Heimdall Governance Studio upload catalogue data?+

No. Catalogue parsing, governance configuration and SQL generation happen locally in your browser.

Which catalogue file formats are supported?+

XLSX, XLS, XLSB, CSV and normalized JSON column-level catalogues are supported. Standard Snowflake information-schema headers are recognized automatically.

Does the application execute SQL in Snowflake?+

No. It generates review-gated SQL files for authorized users to inspect and execute through their approved Snowflake workflow.

Can automation approve governance decisions?+

No. Suggestions and optional CoCo recommendations remain preliminary. Live-schema review, masking review and final governance approval must be confirmed by a person.
